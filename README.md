# Lifeblood: Orange Demo

**Author**: Darian Peters

**Version**: v0.2.3



## Project Overview

Hello! This is the GitHub repository storing all assets, scripts, and scenes for the demo for Lifeblood: Orange! Lifeblood: Orange is a sister game to Lifeblood: Red, acting as a prequel to the events of that game. Set in a world being ravaged by the effects of lifeblood, a strange substance that has the ability to bring fantasy to reality. The protagonist of this story, a strange mannequin brought to life, navigates both the land around them and their own mind, piecing together who they were before their body turned to wood and how they came to the form they are now.



The game's genre is a Metroid-Vania and uses momentum-based physics as its primary source of mobility, utilizing recoil from a shotgun and the swing of a grappling hook to transverse the world. The first complete release of this demo is planned for December 2026.
